# DayNight Pilot — Incident Response Plan

## 1. Incident Severity Definitions

- **SEV-1 (Critical)**: Active cross-tenant data breach, compromise of master encryption key.
- **SEV-2 (High)**: High-confidence prompt injection bypass, rate limiter failure.
- **SEV-3 (Medium)**: Audit chain verification mismatch, localized API error spike.

## 2. Containment & Remediation Workflow

`DETECTION -> CONTAINMENT -> ERADICATION -> RECOVERY -> POST-MORTEM`
