# Microsoft Fluent 2 Design System

Fluent 2 delivers coherent, accessible, and natural user interfaces across Microsoft 365, Teams, and enterprise web applications.

## 1. Visual Language & Materials

- **Acrylic & Mica**: Layered translucency that reflects desktop wallpaper and contextual surroundings.
- **Elevation**: 5 explicit elevation shadows paired with subtle 1px border strokes (`stroke-width: 1px`).
- **Corner Radii**: Standardized curve scale (None: 0px, Small: 2px, Medium: 4px, Large: 8px, XLarge: 12px, Circular: 9999px).

## 2. Component Archetypes

- **CommandBar / Toolbar**: High-density grouping of actions, filters, view switches, and search triggers.
- **Persona & Avatar**: Rich user representation with presence badges (Available, Busy, Away, Offline).
- **Teaching Bubble**: Non-blocking contextual onboarding coachmarks attached to interface elements.
