# IBM Carbon Design System

IBM Carbon is built specifically for data-intensive enterprise web applications, developer platforms, and complex workflow orchestration.

## 1. The 2x Grid System

- Built on an 8px base unit with sub-divisions down to 4px (`mini-units`).
- Spacing scale: `4px`, `8px`, `12px`, `16px`, `24px`, `32px`, `48px`, `64px`.
- Layout grid: 16-column grid for wide enterprise viewports, allowing nested sub-grids.

## 2. Density & Data Presentation

- **Row Sizes for Data Tables**:
  - `compact` (24px height) — Maximum data density for financial monitoring and server logs.
  - `short` (32px height) — Standard data tables.
  - `normal` (48px height) — Consumer-friendly tables with avatar and metadata rows.
  - `tall` (64px height) — Multi-line cell data and action menus.
- **Themes**: Four primary enterprise tokens: White, Gray 10 (light), Gray 90 (dark), Gray 100 (high contrast dark).

## 3. Enterprise UX Patterns

- Persistent side navigation drawers (`Header` + `SideNav`).
- Multi-step wizards with progress steppers and validation indicators.
- In-context batch actions on selected table items.
