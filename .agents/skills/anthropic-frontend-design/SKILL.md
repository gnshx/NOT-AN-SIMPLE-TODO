# Anthropic Frontend Design Skill

## 1. Core Principles
Before writing any frontend code or component, evaluate the interface across four dimensions:
1. **Purpose**: What core action or value does this specific view deliver to the user?
2. **Tone**: Premium, intentional, high-density, authoritative, and intelligent.
3. **Constraints**: WCAG AA accessibility, performance budget, responsive viewports.
4. **Differentiation**: What makes this interface visually distinct from generic, overused boilerplate templates?

## 2. Typography Rules
- **STRICTLY BANNED**: Inter, Arial, Roboto, Helvetica, System Default sans-serif as primary headlines.
- **ENFORCED HEADLINE FONTS**: Syne, Plus Jakarta Sans, Outfit, Space Grotesk.
- **ENFORCED DATA/MONO FONTS**: JetBrains Mono, IBM Plex Mono, Fira Code.

## 3. Visual & Layout Guidelines
- Avoid symmetrical dashboard grid overload. Use intentional asymmetry and focal points.
- Use luminous, glassmorphic surface elevations with subtle border contours.
- High contrast hierarchy: Primary text (`#f8fafc`), Secondary (`#94a3b8`), Muted (`#64748b`).
- Micro-interactions: Fast, responsive hover feedback (<150ms), focused keyboard indicators, and interactive keycaps (`<kbd>`).
