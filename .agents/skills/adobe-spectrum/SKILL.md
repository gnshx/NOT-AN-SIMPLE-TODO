# Adobe Spectrum Design System

Adobe Spectrum powers world-class creative tools (Photoshop, Illustrator, Express, Figma competitors) with precision controls and high information density.

## 1. Density & Scaling Modes

- **Medium Scale**: Optimized for desktop mouse cursor accuracy (compact toolbars, 32px standard inputs).
- **Large Scale**: Scaled for touch devices (tablets, touchscreens, minimum 40px inputs).

## 2. Creative Tool Primitives

- **Dual-Sliders & Range Controls**: High-frequency scrubbing for opacity, saturation, and layer dimensions.
- **Color Wheels & Area Pickers**: Interactive HSL/RGB color manipulation.
- **Floating Tool Palette**: Collapsible vertical/horizontal icon bars with active tool indicators and flyout sub-tools.
