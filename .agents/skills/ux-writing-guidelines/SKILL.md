# UX Writing & Microcopy Guidelines

Writing user interfaces that feel crisp, helpful, and distinctly human.

## 1. Action-Oriented Buttons (CTAs)

- Use **Verb + Noun**:
  - ❌ `Submit`, `OK`, `Continue`, `Process`
  - ✅ `Create Workspace`, `Save Changes`, `Upgrade to Pro`, `Delete Account`
- State consequences clearly: Destructive buttons must name the exact entity being removed (`Delete Project`, not `Yes`).

## 2. Helpful Error Messages

Never show cryptic, blaming, or dead-end errors. Every error message must answer three questions:
1. **What happened?** ("Could not load applications")
2. **Why?** ("Connection to the database timed out")
3. **How to fix it?** ("Check your internet connection and try refreshing the page")

## 3. Inspiring Empty States

Empty states are onboarding opportunities, not blank voids:
- Heading: Positive and clear ("No active jobs yet")
- Description: Brief guidance on how to get started ("Import your first job from LinkedIn or add one manually.")
- Primary Action: Prominent button ("Add Job Application")
