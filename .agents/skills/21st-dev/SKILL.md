# 21st.dev Component Engineering

21st.dev patterns focus on modular, drop-in, beautifully animated React components compatible with shadcn/ui and modern Tailwind setups.

## 1. Philosophy & Conventions

- **Atomic Composability**: Each component is self-contained with minimal external dependencies.
- **Design Alignment**: Built on top of HSL color tokens (`--background`, `--foreground`, `--primary`, `--border`) so components blend seamlessly into any existing theme.
- **Interactive States**: Hover, focus, active, loading, and error states are fully baked in.

## 2. Prompting AI Agents for 21st.dev Quality

When generating components with AI agents:
1. Demand clean semantic HTML tags (`<nav>`, `<article>`, `<section>`, `<aside>`).
2. Enforce Lucide-react or Iconsax icons for consistent stroke-width and iconography.
3. Require responsive breakpoints (`sm:`, `md:`, `lg:`, `xl:`) on all layouts.
4. Strictly disallow unstyled browser buttons or inputs.
