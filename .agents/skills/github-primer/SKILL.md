# GitHub Primer Design System

GitHub Primer is the design system behind GitHub.com, focused on developer productivity, scannability, code readability, and rock-solid dark mode.

## 1. Developer-Focused Components

- **Diff Viewers**: Unified and split code diffs with line-level highlighting, additions (`#2da44e`), and deletions (`#cf222e`).
- **Commit Timeline**: Chronological event streams with avatar nodes and status check icons.
- **Subnavs & Counters**: Clean horizontal tab navigation paired with rounded numerical count badges (`CounterBadge`).
- **Command Palette**: Fast `Cmd+K` searchable modal for navigating repositories, issues, and settings.

## 2. Visual Style

- High-contrast, borders-first layout design using subtle greys (`border-muted`).
- Code typography: `ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas, monospace`.
